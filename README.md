# PDF マークアップ共有

現場タブレットで PDF 図面をリアルタイムに共有・書き込みするアプリです。  
Socket.IO で全端末が即時同期し、PIN 認証でセッションを保護します。

---

## セットアップ

```bash
# リポジトリを取得したら依存パッケージをインストール
npm install

# サーバー起動（デフォルトポート 3000）
npm start
```

起動すると LAN 内の IP アドレスが表示されます。  
同じ Wi-Fi 内の端末からはそのアドレスに接続してください。

---

## インターネット越しに公開（Cloudflare Tunnel）

工事現場など同じ Wi-Fi を使えない場合は Cloudflare Tunnel で HTTPS URL を取得します。

```bash
# サーバーを起動した状態で別ターミナルで実行
npx cloudflared tunnel --url http://localhost:3000
```

表示された `https://xxxx.trycloudflare.com` が共有 URL になります。  
**セッション URL と PIN をセットで作業員へ伝えてください。**

---

## PM2 で常駐起動（本番運用）

```bash
# PM2 をグローバルインストール（初回のみ）
npm install -g pm2

# 設定ファイルで起動
pm2 start pm2.config.js

# サーバー再起動後も自動起動させる
pm2 save
pm2 startup
```

ログの確認:

```bash
pm2 logs pdf-markup
```

## 環境変数

`.env.example` をコピーして `.env` を作成し、必要に応じて変更してください。

```bash
cp .env.example .env
```

| 変数 | デフォルト | 説明 |
|------|-----------|------|
| `PORT` | `3000` | サーバーのポート番号 |
| `SESSION_TTL_HOURS` | `24` | セッション有効期限（時間）。期限切れ後は自動削除 |

## 役割別 操作手順

### 管理者（検修責任者 / 工事管理者）

1. ブラウザで `http://localhost:3000` を開く（または LAN の IP アドレス）
2. PDF 図面ファイルを選択
3. **参加 PIN**（4 桁以上の数字）を設定して「セッションを作成」
4. 表示された **QR コード** と **PIN** を作業員に共有する
5. 自分もセッション URL を開いて参加

### 作業員

1. 表示された QR コードをスキャン、または URL を直接入力
2. **PIN**・**氏名**・**役割** を入力して「セッションに参加」
3. PDF が表示されたらマークアップを開始

### 線閉責任者（解除操作）

1. 他の参加者と同様に参加（役割：**線閉責任者**）
2. ツールバーの「**解除**」ボタンをタップ
3. 解除したいマークをタップして選択（複数選択可）
4. 「**解除を確定**」をタップ → 全員の画面でそのマークが解除済みに変わる

## 操作リファレンス

| 操作 | 説明 |
|------|------|
| タップ / マウスドラッグ | マークアップを描画 |
| 長押し（0.6 秒） | 自分のストロークを削除（確認バナーが表示） |
| ピンチ | ズームイン / アウト |
| 2 本指スワイプ | ページスクロール |
| 「↩ 戻す」ボタン | 直前に描いた自分のストロークを 1 件削除 |
| 「解除済み表示」トグル | 解除済みマークの薄い残像を表示 / 非表示 |
| 「QR」ボタン | セッション URL の QR コードを表示 |

## 技術構成

- **Node.js** + **Express** — HTTP サーバー
- **Socket.IO** — リアルタイム双方向通信
- **PDF.js** (CDN) — ブラウザ内 PDF レンダリング
- **QRCode.js** (CDN) — QR コード生成
- データ永続化: **インメモリのみ**（サーバー再起動でセッション消去）
